# Exercise-06b-Animations

InkScene is my project.

The main objective of the game is to find three red cubes in the scene. Once the player gets close to them, they can press F or C to destroy them.

In addition to the default WASD movement controls, the E key is used for dialogue interactions.
Both the F and C keys are used for attack actions, they have the same functionality, and the only difference being their animations.

The functions of these three keys are also displayed on the canvas.

At the same time, the canvas shows the number of cubes that have been destroyed, out of a total of three. (Due to layout issues caused by the inky content, I was not able to adjust the canvas very well.)

When the player presses F or C, if a red cube is within a certain range, the game will play an animation, destroy the cube, and update the score.

For the dialogue system, I visually hid the cube used to trigger dialogue and placed a character model at the same position instead.
